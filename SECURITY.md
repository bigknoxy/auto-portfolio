# Security Policy

## Supported Versions

| Version | Supported |
|----|----|
| 0.1.x | ✅ |

## Reporting a Vulnerability

Please report vulnerabilities via GitHub Security Advisories:

1. Navigate to the **Security** tab on this repository
2. Click **Report a vulnerability**
3. Describe the issue and any reproduction steps

The maintainer (`@bigknoxy`) will respond within **48 hours** and triage the report.

### What not to do

- Do NOT open a public issue for security-sensitive vulnerabilities
- Do NOT commit credentials or secrets to this repo
